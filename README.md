# دانا — سامانه مدیریت مدارس

آخرین تطبیق مستندات با کد: **2026-10-30**.

رابط فارسی و راست‌به‌چپ شش نقش با بک‌اند واقعی TypeScript/Fastify، PostgreSQL، Redis/BullMQ و فایل خصوصی سازگار با S3. منبع داده سرور است؛ قطع API باعث برگشت به داده نمونه نمی‌شود.

## شروع محلی

Node.js 22، npm و Docker Compose لازم‌اند. متغیرهای `.env.example` را در محیط خود تنظیم کنید؛ فایل `.env` موجود را بازنویسی نکنید. پیش از migration/seed مقصد DATABASE_URL و MIGRATION_DATABASE_URL را بررسی کنید. مقادیر نمونه فقط برای توسعه محلی‌اند.

```sh
npm ci
docker compose up -d
npm run db:migrate
npm run storage:init
npm run dev
```

در ترمینال جدا:

```sh
npm run worker
```

| مسیر/سرویس توسعه | نشانی |
| --- | --- |
| صفحه معرفی | http://localhost:3000/ |
| ورود | http://localhost:3000/login |
| داشبورد نقش مجاز | `/dashboard/<role>` |
| API از مبدأ رابط | `/api/v1`؛ پراکسی به پورت داخلی 3001 |
| PostgreSQL، Redis، MinIO | به‌ترتیب loopback روی 55432، 56379 و 59000 |

worker برای ارسال‌های صف‌شده، اعلان گروهی زنگوله و نگهداری آمار لازم است؛ `npm run dev` آن را اجرا نمی‌کند. در تولید فقط app روی loopback:3000 منتشر می‌شود و API جداگانه پورت عمومی ندارد.

ورود از گوشی همان شبکه با `http://<IP لپ‌تاپ>:3000/login` در development مجاز است؛ میزبان و فایروال باید اجازه اتصال بدهند. استثنای IP شبکه توسعه به تولید منتقل نمی‌شود.

## ساخت حساب و داده آزمایشی

- نخستین مدیر با متغیرهای `BOOTSTRAP_USERNAME/NAME/PHONE/PASSWORD` و `npm run admin:create` ساخته می‌شود؛ رمز حداقل ۱۲ نویسه است. متغیرهای bootstrap را پس از اجرا حذف کنید.
- ثبت‌نام عمومی و رمز پیش‌فرض وجود ندارد. ورود با شناسه/رمز یا شناسه/پیامک مستقل است؛ کد دوم بعد از رمز اجباری نیست.
- داده نمونه فقط با `npm run db:seed` و در توسعه ساخته می‌شود. حساب‌های ساخته‌شده در `.local/browser-fixture.json` و کد پیامکی توسعه در `.local/otp/` هستند؛ این فایل‌ها نباید منتشر یا وارد Git شوند.
- `npm run db:seed:teacher-preview -- --with-history` داده نمایشی دبیر و سابقه ساختگی صریح می‌سازد؛ برای محیط زنده نیست.

## قابلیت‌های موجود

- حساب و نشست، چند نقش/مدرسه/فرزند، مجوز معاون و کنترل دسترسی سرور.
- ثبت‌نام سالانه، کلاس، کادر، برنامه، حضور امروز و اصلاح جلسه قبلی با تاریخچه.
- میز کار دبیر، عملکرد محدود همان درس، نمره، تکلیف/تحویل/بازخورد، زمان‌بندی آزمون و کارنامه رسمی جداگانه.
- تعرفه، اقساط، تخفیف، رسید دستی و تأیید مالی تراکنشی؛ حساب سال‌های مختلف مستقل.
- اطلاعیه، سنجاق/بایگانی منطقه‌ای، بانک سؤال، تبلیغ دارای مقصد و فایل خصوصی.
- فعال/فقط مشاهده/تعلیق مدرسه، فعال‌سازی دوباره حساب مدیر، تیکت خصوصی با پیوست و ارجاع.
- زنگوله شخصی، خواندم، پیام مدیران و پیام دبیر در محدوده کلاس/درس؛ اعلان اختیاری اطلاعیه در پس‌زمینه.
- نمای نظارتی خواندنی مدارس و پرونده‌ها برای مدیر پلتفرم با ممیزی.
- آمار تجمیعی رویداد، کاربران یکتا، تبلیغات و معرفی دانا پلاس؛ نگهداری خام قابل تنظیم، پیش‌فرض ۱۸۰ روز.

پیامک و ارسال مستقیم بله به تنظیم واقعی سرویس وابسته‌اند. اتصال شخصی بله و وب‌هوک امن در کد وجود دارد، اما راه‌اندازی زنده در محیط مقصد لازم است. پرداخت آنلاین، موتور شرکت/تصحیح آزمون آنلاین، فرمول خودکار معدل و همگام‌سازی آفلاین کامل پیاده نشده‌اند. دانا پلاس فعلاً معرفی است؛ فروش و ثبت‌نام دوره ندارد.

## بررسی و ساخت

بررسی معمول و سبک:

```sh
npm run lint_applet
npm run compile_applet
```

بسته تولیدی سرور: `npm run build:server`. آزمون‌های `test:api`، `test:legacy` و `test:browser` مجموعه‌های جدا با پیش‌نیاز خودند؛ با ویرایش مستندات خودکار اجرا نمی‌شوند. اجرای `test:load` برای این تحویل لازم نیست و طبق درخواست کاربر اجرا نمی‌شود.

آزمون محدود عملیات پلتفرم: `node --import tsx --test server/tests/school-access-support.test.ts`. سرویس محلی لازم دارد، فایل/وب‌هوک را شبیه‌سازی و داده خودش را پاک می‌کند؛ برای جلوگیری از رقابت fan-out از TEST_DATABASE_URL جدا یا worker متوقف استفاده کنید. [دامنه شواهد و محدودیت‌ها](docs/VALIDATION.md).
