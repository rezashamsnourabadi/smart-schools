# سامانه هوشمند قطب مدارس شهرستان (School Management & Regional Hub)

> پلتفرم جامع، مدرن و یکپارچه مدیریت مدارس شهرستان با رویکرد **تلفن همراه (Mobile-First)**، پیام‌رسانی بومی (پیام‌رسان بله و سامانه پیامک) و تفکیک نقش‌های شش‌گانه آموزشی و مدیریتی.

---

## 📖 معرفی سامانه (Project Overview)

این سامانه برای ساماندهی یکپارچه فرآیندهای آموزشی، انضباطی، ارتباطی و مالی در سطح مدارس یک شهرستان یا منطقه آموزشی طراحی شده است. از ویژگی‌های متمایز این پلتفرم، ارتباط لحظه‌ای با اولیا از طریق شبیه‌ساز پیام‌رسان بله و پیامک کشوری، بانک سراسری سوالات، کارپوشه جامع تحصیلی دانش‌آموزان و پنل اختصاصی مدیریت تبلیغات و حامیان فرهنگی/آموزشی منطقه است.

---

## 👥 نقش‌های کاربری و ماتریس دسترسی (Role-Based Access)

سامانه دارای ۶ سطح کاربری کاملاً تفکیک‌شده است:

| نقش کاربری | عنوان در سامانه | دسترسی‌ها و وظایف اصلی |
| :--- | :--- | :--- |
| **Platform Admin** | مدیر ارشد پلتفرم شهرستان | نظارت کلان بر مدارس، پایش پیامک و بله، تخصیص بودجه، مدیریت بانک سوالات و حامیان مالی |
| **Principal** | مدیر آموزشگاه | مدیریت کامل مدرسه، تایید رویدادها، کلاس‌بندی، چیدمان برنامه هفتگی، تفویض دسترسی به معاونان |
| **Vice Principal** | معاون آموزشی / اجرایی | حضور و غیاب کلاسی، ثبت تاخیر/غیبت، ثبت موارد انضباطی، پیگیری تکالیف (بر اساس مجوزهای اعطایی مدیر) |
| **Teacher** | دبیر / آموزگار | حضور و غیاب سریع سر کلاس، دفتر نمرات مستمر، تعریف تکالیف، آزمون آنلاین، ارسال سوال به بانک منطقه |
| **Student** | دانش‌آموز | مشاهده برنامه درسی روزانه، تکالیف، آزمون‌های آنلاین، سوال تمرینی روز و کارنامه تحصیلی |
| **Parent** | اولیای دانش‌آموز | آگاهی لحظه‌ای از ورود/خروج و غیبت فرزند، مشاهده اطلاعیه‌ها در بله/SMS، مشاهده کارنامه و ویرایش تماس |

## 🚀 ویژگی‌های کلیدی (Key Features)

1. **طراحی واکنش‌گرا و بهینه‌سازی موبایل (Mobile-First UX):**
   - نوار ناوبری اختصاصی پایین صفحه (`MobileBottomNav`) برای دسترسی تک‌لمسی به منوهای پرکاربرد در تلفن همراه.
   - پنجره‌های کشویی و فرم‌های تمام‌صفحه متناسب با استانداردهای ارگونومی لمسی (حداقل اندازه هدف ۴۴ پیکسل).

2. **فارسی‌سازی کامل و اعداد فارسی (Persian Numerals):**
   - ماژول کمکی `persianUtils.ts` برای تبدیل تمام ارقام (نمرات، درصدها، ساعت‌ها، کد ملی و شماره تلفن) به اعداد فارسی.

3. **سامانه ارسال پیامک هوشمند و اتصال به پیام‌رسان بله:**
   - با ثبت غیبت یا تاخیر توسط دبیر یا معاون، پیام اطلاع‌رسانی خودکار تولید و در قالب Toast و سابقه پیام‌ها به حساب بله و شماره ولی مخابره می‌شود.

4. **پرونده و کارپوشه کامل دانش‌آموز (Comprehensive Dossier):**
   - مشخصات هویتی و امکان به‌روزرسانی اطلاعات تماس توسط اولیا.
   - ریزنمرات رسمی نوبت اول و دوم، محاسبه خودکار معدل و ضرایب دروس.
   - تاریخچه انضباطی با تفکیک موارد تشویقی و تذکرات.
   - سوابق تحصیلی پایه‌های گذشته.

5. **بانک سوالات سراسری شهرستان (Regional Question Bank):**
   - اشتراک‌گذاری نمونه‌سوالات تستی و تشریحی میان دبیران شهرستان با فیلتر پایه، درس، درجه سختی و امکان استفاده در آزمون‌ها.

6. **برنامه‌ریز هفتگی دروس (Schedule Planner):**
   - چیدمان گرافیکی روزهای هفته (شنبه تا چهارشنبه) در ۴ زنگ با انتصاب درس و دبیر.

7. **مدیریت اخبار، اطلاعیه‌ها و رویدادها (Post & Event Manager):**
   - انتشار اطلاعیه‌های فوری، اخبار آموزشگاه و گزارش رویدادها و جلسات انجمن اولیا و مربیان.

8. **تنظیم هوشمند سطوح دسترسی معاون‌ها توسط مدیر:**
   - امکان فعال/غیرفعال‌سازی ۵ سطح دسترسی مجزا برای معاون آموزشگاه بدون نیاز به تغییر کد.

9. **دفتر نمرات، تکالیف و آزمون آنلاین دبیران:**
   - ثبت سریع نمرات مستمر، تعریف تکالیف با مهلت زمانی و زمان‌بندی آزمون‌های آنلاین.

10. **مدیریت سال و تقویم تحصیلی و ویزارد ارتقا (Academic Rollover):**
    - تعریف سال‌های تحصیلی با ۳ وضعیت فعال، برنامه‌ریزی‌شده و بایگانی‌شده، سوییچ نوبت‌ها و ارتقای اتوماتیک پایه‌ها و فارغ‌التحصیلی سال دوازدهم همراه با انجماد سوابق تحصیلی گذشته.

11. **مرکز تعاملی مستندات و کاتالوگ فیچرها درون برنامه (System Docs & Feature Book):**
    - دسترسی فوری از طریق هدر و فوتر به کاتالوگ تفکیک‌شده فیچرها، ماتریس دسترسی نقش‌ها (RBAC)، مشخصات فنی و ارزش‌های تجاری ویژه سرمایه‌گذاران با قابلیت چاپ و کپی سریع.

12. **کلاس‌بندی، ظرفیت‌ها و تفکیک فارغ‌التحصیلان و انتقالی‌ها:**
    - ساماندهی اتاق‌های درس، انتصاب دبیران راهنما و نگهداری سوابق تحصیلی و دانشگاهی فارغ‌التحصیلان.

## 🛠️ پشته فناوری (Tech Stack)

- **Frontend:** React 19 + TypeScript
- **Bundler & Tooling:** Vite 6 + ESBuild
- **Styling:** Tailwind CSS v4 (RTL Layout)
- **Icons:** Lucide React
- **Animations:** Motion (`motion/react`)
- **State Management:** React Context API (`AppContext.tsx`)
- **Backend Architecture:** Ready for full-stack integration (Express + Node / Firebase Firestore)

## 💻 راه‌اندازی و اجرا (Quick Start)

### پیش‌نیازها:
- Node.js نسخه 18 یا بالاتر
- npm یا bun

### دستورات اجرا:
```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای سرور توسعه (پیش‌فرض پورت ۳۰۰۰ و هاست 0.0.0.0)
npm run dev

# ۳. بررسی خطاهای تایپ‌اسکریپت و لینت
npm run lint

# ۴. بیلد نهایی برای انتشار
npm run build
```

## 🛡️ اصول مهم توسعه و نگهداری (Best Practices)

- **اعداد فارسی در کد:** هرگز ارقام فارسی (`۴`, `۰`) را مستقیماً در متغیرهای عددی جاوااسکریپت ننویسید. همواره ارقام انگلیسی نوشته شده و در زمان رندرینگ با `toPersianDigits()` تبدیل شوند.
- **توسعه چندنقشی:** برای تست عملکرد هر ویژگی، از نوار `RoleQuickSwitch` استفاده کرده و صحت تجربه کاربری در هر نقش را ارزیابی کنید.
- **بهینه‌سازی موبایل:** هر کامپوننت جدید باید در عرض‌های کوچک (۳۶۰ تا ۴۲۰ پیکسل) به دقت تست شود.
