# سامانه مدیریت مدارس

رابط فارسی و راست‌به‌چپ شش نقش، متصل به API واقعی Fastify، PostgreSQL، Redis و فایل خصوصی S3. ظاهر پنل‌ها حفظ شده است؛ خرابی API به داده نمونه برنمی‌گردد.

## اجرای محلی

نیازمندی‌ها: Node.js 22، npm و Docker Compose. متغیرهای `.env.example` را در `.env` تنظیم کنید. فایل محیط موجود را بازنویسی نکنید؛ مقادیر نمونه فقط برای توسعه هستند.

```sh
npm ci
docker compose up -d
npm run db:migrate
npm run storage:init
npm run dev
```

برنامه روی `http://localhost:3000` است. API داخلی روی 3001 و پراکسی `/api/v1` در همان مبدأ است. worker اعلان را جدا با `npm run worker` اجرا کنید.

نخستین مدیر با تنظیم امن متغیرهای BOOTSTRAP_USERNAME، BOOTSTRAP_NAME، BOOTSTRAP_PHONE و BOOTSTRAP_PASSWORD و فرمان `npm run admin:create` ساخته می‌شود. رمز حداقل 12 نویسه است و رمز پیش‌فرض وجود ندارد. متغیرها را پس از اجرا پاک کنید. مدیران تأیید دوم دارند.

داده آزمایشی فقط با فرمان صریح `npm run db:seed` ساخته می‌شود؛ در تولید ممنوع است. مشخصات حساب‌های توسعه در `.local/browser-fixture.json` و کد پیامکی محلی در `.local/otp/<challengeId>.json` هستند؛ هیچ‌کدام از وب ارائه نمی‌شوند.

## امکانات متصل

- حساب، نشست، بازیابی، چند عضویت و چند فرزند؛ کنترل مجوز سمت سرور و RLS مدرسه.
- ثبت‌نام سالانه، کلاس، پرسنل، برنامه و حضور؛ دفتر نمره، تکلیف و تحویل، زمان‌بندی آزمون و انتشار کارنامه رسمی مستقل.
- تعرفه، تخفیف، پرداخت دستی و تأیید رسید با تراکنش و قفل؛ تاریخچه سال‌ها مستقل.
- اطلاعیه، بانک سؤال، حامیان، فایل خصوصی و outbox اعلان.

پیامک، بله و بانک به اطلاعات اتصال واقعی نیاز دارند. پرداخت آنلاین تا اتصال درگاه غیرفعال است؛ ارسال بیرونی ناموجود، موفق نشان داده نمی‌شود. موتور شرکت آنلاین در آزمون، فرمول خودکار معدل، ثبت آفلاین و ورود خودکار اطلاعات قدیمی مرورگر در این نسخه وجود ندارند.

## بررسی و ساخت

```sh
npm run lint_applet
npm run compile_applet
npm run build:server
npm run test:legacy
npm run test:api
npm run test:browser
```

آزمون API به سرویس‌های محلی و مرورگر به برنامه در حال اجرا و fixture صریح نیاز دارد. Playwright در ویندوز Edge نصب‌شده را به کار می‌گیرد؛ در Linux ابتدا Chromium آن را نصب کنید. آزمون بار طبق درخواست کاربر متوقف شده و برای اجرای برنامه لازم نیست؛ ظرفیت تضمین‌شده اعلام نشده است.
